* Notecard app

This is a simple index card file app, in Python 3.14/QT PySide6/SQLite3.  Developed on Windows 11 w/ VS Code.  Not useful at present, can edit sample data but no edit or delete.  Somewhat nice separation of concerns between View, Controller, Model using message system between controller and view.
